# Simulation scripts

Simulations and analyses of Picton, Madrid, Pazzaglia et al.,
[*A spinal circuit for collective coordination*](https://arxiv.org/abs/2608.25909),
arXiv:2608.25909 (2026).

All scripts must be launched **from the repository root**, e.g.

```bash
python run_sim_files/ex_vivo_simulations/in_silico_pacing/run_in_silico_pacing.py
```

Simulation outputs are written to `RESULTS_PATH`, curated results used by the
post-processing are stored in `ANALYSIS_PATH`, and the pre-computed leader wakes
are read from `WATER_DYNAMICS_PATH`. Defaults and the corresponding environment
variables are defined in [`network_experiments/snn_paths.py`](../network_experiments/snn_paths.py).

```
run_sim_files/
├── model_calibration/          Calibration of the neuromechanical model (Supp. §2–3)
│   ├── open_loop_network/      Synaptic weights → open-loop oscillations of the isolated network
│   └── motor_output_gains/     Motor output gains G_MC → zebrafish swimming kinematics
├── ex_vivo_simulations/        Counterpart of the ex vivo (paralysed) preparations (Supp. §4)
│   ├── simulation_runner.py    Shared runner: muscles silenced, body bent in position control
│   ├── static_bending/
│   ├── in_silico_pacing/       Fig. 3F–H
│   └── in_silico_schooling/    Fig. 3I–J
└── in_vivo_simulations/        Counterpart of the freely swimming fish (Supp. §3, §5)
    ├── proprioception_on_off/
    └── vortex_matching/        Fig. 4A–F, Fig. 4L–M, muscle stiffness sweep
        └── post_processing/
```

## Ex vivo simulations

The simulated muscles are silenced and the body joints (except the first head
joint) are bent in position control, as in the ex vivo experiments. The network
generates the locomotor rhythm and receives sensory feedback from the
position-controlled body.

| Paper | Experiment | Folder | Pipeline |
|---|---|---|---|
| Results, Supp. §4 | Static bending | [`static_bending`](ex_vivo_simulations/static_bending) | `run_static_bending.py` |
| Fig. 3F–H, Supp. §4 | In silico pacing | [`in_silico_pacing`](ex_vivo_simulations/in_silico_pacing) | `run_in_silico_pacing.py` → `move_results.py` |
| Fig. 3I–J, Supp. §4 | In silico schooling | [`in_silico_schooling`](ex_vivo_simulations/in_silico_schooling) | `run_in_silico_schooling.py` → `move_results.py` |

## In vivo simulations

The network controls the body through the muscle model and receives sensory
feedback from the resulting movements (closed loop).

| Paper | Experiment | Folder | Pipeline |
|---|---|---|---|
| Results, "In silico neuromechanical model" | Proprioception ON vs OFF during self-driven swimming | [`proprioception_on_off`](in_vivo_simulations/proprioception_on_off) | `run_proprioception_on_off.py` |
| Fig. 4A–F, Supp. §5 | Vortex phase matching (closed vs open loop) | [`vortex_matching`](in_vivo_simulations/vortex_matching) | `run_vortex_phase_matching.py` → `move_results_phase_matching.py` → `post_processing/plot_vortex_phase_matching.py` |
| Fig. 4L–M, Supp. §5–6 | Energy consumption with and without vortices | [`vortex_matching`](in_vivo_simulations/vortex_matching) | `run_energy_consumption.py` → `move_results_energy_consumption.py` → `post_processing/plot_energy_consumption.py` |
| Supp. §5 | Vortex phase matching vs muscle stiffness | [`vortex_matching`](in_vivo_simulations/vortex_matching) | `run_muscle_stiffness_sweep.py` → `move_results_muscle_stiffness_sweep.py` → `post_processing/plot_muscle_stiffness_sweep.py` |

### Leader wake

The follower fish swims in the flow field generated by a leader fish whose
midline follows the recorded leader tail-beat sequence (Supp. Eq. 13). The flow
fields were computed with a 2D boundary data immersion method (BDIM, based on
[WaterLily.jl](https://github.com/WaterLily-jl/WaterLily.jl)) and are loaded from
`WATER_DYNAMICS_PATH`. The folder used for all paper simulations is selected in
the run scripts with

```python
sim_runner.get_water_dynamics_file_name(
    amp_scaling        = 1.00,
    freq_scaling       = 0.25,
    integration_method = 'abdquickest',
    speed_type         = 'fast',
    amp_type           = 'constant',
    step_bounds        = [12104, 12264],
    freq_bounds        = (None, None),
    matching_string    = 'sketch_body',
)
```

which must match exactly one folder in `WATER_DYNAMICS_PATH`, containing
`parameters.yaml`, `kinematics_signals.csv`, `steady_loop.json`, `uv_field/`
and `curluv/` (≈6.4 GB).

Each vortex-matching study is a batch of independent simulations run in
parallel (`analysis_runner.run_analysis`):

| Study | Simulations |
|---|---|
| Phase matching | 41 × 9 positions × 5 seeds with vortices + 5 in pure flow, for PS weights 20 and 0 |
| Energy consumption | 50 seeds × (with vortices, pure flow), for PS weights 20 and 0 |
| Muscle stiffness | 41 × 9 positions × (5 seeds × 2 feedback modes + 1 passive body), for 16 natural frequencies |

To limit disk usage, large raw files (network state, monitors, FARMS hdf5) are
deleted while a batch is running; only the processed data used by the
post-processing is kept.
